# Blackwell

Blackwell is a JAX-native library for probabilistic robotics. Its v0.1 scope is
deliberately compact: manifold-aware uncertainty, Gaussian and particle
beliefs, nonlinear filtering, simulation and uncertainty evaluation.

The project is in the interface-spike stage. The package layout and development
tooling are established; the initial experiments will define the public
interfaces before filter APIs are committed.

## Project boundaries

This documentation is for the software package. Longer explanations, book
chapters, exercises and extended notebooks are maintained separately from this
repository.
